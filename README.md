\# JavaFX Academic Projects



This repository contains two JavaFX-based academic projects developed in Java.  

The projects focus on data structures, file handling, GUI design, expression processing, and dynamic reporting.



\---



\## 1. Hospital Management System



\### Description



The \*\*Hospital Management System\*\* is a JavaFX-based desktop application designed to manage hospital-related data such as patients, conditions, treatments, medications, and symptoms.



The system uses a custom doubly linked list structure for storing and managing data, with support for loading information from files and generating dynamic reports.



\### Features



\- Patient management module

\- Condition management module

\- Treatment management module

\- Medication management module

\- Symptom management module

\- Custom doubly linked list storage

\- File-based data loading

\- Dynamic reporting

\- JavaFX graphical user interface



\### Technologies Used



\- Java

\- JavaFX

\- Custom Data Structures

\- File Handling



\### Key Concepts



\- Doubly Linked List

\- Object-Oriented Programming

\- GUI Development

\- Data Management

\- Dynamic Reports

\## 2. Expression Processor  

\### Notation Conversion System



\### Description



The \*\*Expression Processor\*\* is a configurable JavaFX application that processes mathematical expressions and supports conversion between different expression notations.



The system supports infix, prefix, and postfix conversions, allows custom operator precedence to be loaded from external files, and performs stack-based expression evaluation.



\### Features



\- Infix expression processing

\- Prefix expression processing

\- Postfix expression processing

\- Conversion between infix, prefix, and postfix notations

\- Custom operator precedence loaded from external files

\- Stack-based expression evaluation

\- JavaFX graphical user interface



\### Technologies Used



\- Java

\- JavaFX

\- Stack Data Structure

\- File Handling



\### Key Concepts



\- Stack-based evaluation

\- Expression notation conversion

\- Operator precedence

\- Object-Oriented Programming

\- GUI Development
